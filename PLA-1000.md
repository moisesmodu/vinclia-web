## La idea en una frase

Vender a negocios de Lleida lo que ya funciona en Algorithmics: **web + WhatsApp con IA que
reserva solo**. El producto existe (`algorithmics-portal/lib/wa-*.ts`, Stripe, Resend, Neon),
la marca existe (vinclia.tech, precios puestos) y el caso real existe (358 conversaciones,
14 % de reservas desde el bot). Falta **fabricar demos y enseñarlas**.

## Los números

| | |
|---|---|
| Objetivo | 1.000 €/mes recurrentes |
| Pack Presència Total | 990 € alta + 149 €/mes |
| Clientes necesarios | **7** (= 1.043 €/mes) |
| Ingreso de alta por el camino | 6.930 € (una sola vez) |
| Coste variable por cliente | ≈ 5–10 €/mes (dominio, WhatsApp API ~0,017 €/msg desde oct. 2026, Claude) |
| Margen sobre la cuota | > 90 % |
| Conversión esperada demo → cliente | 1 de cada 8–10 |
| Demos necesarias | ≈ 60–70 |
| Ritmo | 10 demos/semana → **7 clientes en 7–9 semanas** |

Si una semana no entra nadie, el ritmo baja a 12 semanas. No hay atajo: la variable que
manda es cuántas demos personalizadas ve un dueño de negocio.
