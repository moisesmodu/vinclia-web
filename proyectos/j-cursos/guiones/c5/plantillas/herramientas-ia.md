# Herramientas de vibe coding: cuál usar para qué

Curso «Vibe coding: crea apps y webs con IA sin saber programar». Clase 3.

Datos revisados en noviembre de 2026. **Los precios y los límites cambian a menudo:** antes de pagar, mira siempre la página oficial de cada herramienta.

---

## Las tres familias

| Familia | Ejemplos | Para qué |
|---|---|---|
| Chats de IA | Claude, ChatGPT, Gemini | Webs y apps de un solo archivo |
| Constructores en el navegador | Lovable, Bolt, v0, Replit | Apps con usuarios y base de datos |
| En tu ordenador | Cursor, Claude Code, GitHub Copilot | Proyectos grandes y reales |

## Chats de IA (la herramienta de este curso)

- **Claude** (Anthropic): enseña la web al lado del chat, en los «artefactos».
- **ChatGPT** (OpenAI): tiene un lienzo llamado «Canvas».
- **Gemini** (Google).
- Todos tienen plan gratuito con límite de uso. Los planes individuales de pago rondan los 20 euros al mes.

## Constructores de apps en el navegador

- **Lovable**: el más pensado para quien no programa.
- **Bolt**, **v0** (de Vercel) y **Replit**: parecidos.
- Crean la app entera, con base de datos y cuentas de usuario (a menudo con Supabase).
- Plan gratuito con créditos diarios o mensuales limitados. Los de pago rondan los 20-25 euros al mes.

## Para trabajar en tu ordenador

- **Cursor**: editor de código con IA. Plan gratuito limitado.
- **Claude Code**: agente que trabaja en la terminal. Necesita un plan de pago de Claude o una clave de API.
- **GitHub Copilot**: la IA dentro de VS Code.
- **Git y GitHub**: guardar versiones y volver atrás. GitHub es gratis para repositorios públicos y privados.

## Publicar en internet

| Servicio | Plan gratuito | Ojo con |
|---|---|---|
| Netlify Drop | Arrastras la carpeta a app.netlify.com/drop | Uso comercial dentro de sus límites |
| GitHub Pages | Gratis con tu cuenta | Revisa sus condiciones para uso comercial |
| Vercel | Plan Hobby | Solo uso personal no comercial |

## Qué usar según lo que quieras

| Si quieres… | Usa |
|---|---|
| Una web o herramienta sencilla | Un chat gratuito y un archivo index.html |
| Una app con usuarios y datos | Lovable o Bolt, y una revisión técnica |
| Un proyecto grande en tu ordenador | Cursor o Claude Code |
| Publicar sin pagar | Netlify Drop |
