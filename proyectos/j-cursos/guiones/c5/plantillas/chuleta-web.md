# Chuleta: las tres partes de una web

Curso «Vibe coding: crea apps y webs con IA sin saber programar». Sección 2.

---

## La casa

| Parte | Es como… | Decide… |
|---|---|---|
| HTML | Las paredes y los muebles | Qué hay: títulos, campos, botones |
| CSS | La pintura y la decoración | Cómo se ve: colores, tamaños, espacios |
| JavaScript | La electricidad | Qué pasa al pulsar o escribir |

En tus apps del curso, las tres partes van en un solo archivo, `index.html`: arriba el CSS (dentro de `<style>`), en medio el HTML y abajo el JavaScript (dentro de `<script>`).

## Lo que quieres cambiar, y dónde está

| Quiero cambiar… | Está en |
|---|---|
| Un texto, un campo o un botón nuevo | HTML |
| Un color, un tamaño o un espacio | CSS |
| Cómo se ve en el móvil | CSS |
| Un cálculo o qué pasa al pulsar | JavaScript |
| Que algo se guarde o se copie | JavaScript |

## Palabras que vas a ver mucho

| Palabra | Qué quiere decir |
|---|---|
| `function` | Una receta con nombre |
| `const`, `let` | Una caja con un nombre y un valor |
| `if` | Si pasa esto, haz aquello |
| `getElementById` | Busca el elemento con ese id |
| `addEventListener` | Cuando pase algo (un clic), ejecuta esto |
| `//` | Comentario: una nota para personas |
| `class`, `id` | Nombres de enganche para el CSS y el JavaScript |
| `#0E9F8E` | Un color escrito en código |

## Cambios que puedes hacer tú

- **Un texto:** búscalo con Control F (Comando F en Mac) y cámbialo.
- **Un color:** busca `--acento` al principio del archivo y cambia el código de color.
- **Un número:** por ejemplo, la propina que sale marcada al empezar.
- Después: **guarda, recarga** (F5 o Comando R) **y comprueba**. Si algo se rompe, Control Z.

## Instrucciones útiles

- «En el CSS, cambia solo [qué]. No toques el HTML ni el JavaScript.»
- «Explícame este trozo línea a línea como si no supiera programar. Usa un ejemplo con números: [datos].»
- «Pon comentarios en castellano que expliquen qué hace cada parte. No cambies nada del código.»
- «Usa nombres en castellano para todo lo que crees.»
- «Uso [Windows/Mac] y [navegador]. Explícame paso a paso cómo guardar el código como index.html y abrirlo.»

```
Documentos/
  propinas/
    v1/index.html
    v2/index.html
    v3/index.html
    instrucciones.txt
```

- Bloc de notas: en «Guardar como», tipo «Todos los archivos» y codificación UTF-8. Cuidado con `index.html.txt`.
- TextEdit (Mac): menú Formato, «Convertir a texto normal».
- Consola del navegador: F12 o clic derecho, «Inspeccionar», pestaña Consola. Los errores salen en rojo.
