# Plantilla: presupuesto claro

Clase c3-18. La IA ordena y redacta. Las sumas las compruebas tú; el tipo de impuesto lo confirmas con tu gestoría o tu programa de facturación. En la IA, el cliente es «cliente A»: sus datos reales van en tu programa.

## 1. Estructura
| Parte | Para qué sirve |
|---|---|
| Datos tuyos y del cliente | Se completan en tu programa, no en la IA |
| Descripción del trabajo | Qué se va a hacer, en una o dos frases |
| Partidas: materiales | Cada material con su importe |
| Partidas: mano de obra | Horas o jornadas y su importe |
| Base imponible | Suma de partidas, comprobada por ti |
| Impuestos | Tipo indicado por ti o tu programa |
| Qué no incluye | Evita discusiones después |
| Plazo de ejecución | Cuándo empezarías y cuánto dura |
| Validez | Hasta cuándo vale el precio |
| Forma de pago | Adelanto, transferencia, Bizum… |

## 2. Instrucciones para copiar
**De notas a presupuesto**
> Convierte mis notas en un presupuesto ordenado para cliente A. Notas: [pega tus notas tal cual]. Separa materiales y mano de obra, añade qué no incluye, plazo, validez y forma de pago. Calcula la base sin impuestos y deja el IVA para que lo ponga yo.

**Revisión como cliente**
> Revisa este presupuesto como si fueras el cliente. Dime 3 cosas que podrían generar dudas o discusiones y cómo aclararlas. No cambies ninguna cifra.

**Mensaje para enviarlo**
> Escribe un mensaje corto de WhatsApp para enviar este presupuesto a cliente A. Tono cercano y profesional. Ofrece resolver dudas por teléfono y recuerda la validez.

## 3. Antes de enviar
- [ ] He sumado cada partida con la calculadora o la hoja de cálculo.
- [ ] El tipo de impuesto lo he puesto yo.
- [ ] Está claro qué no incluye y qué pasa con imprevistos.
- [ ] Plazo, validez y forma de pago escritos.
- [ ] Datos del cliente añadidos en mi programa, no en el chat.
